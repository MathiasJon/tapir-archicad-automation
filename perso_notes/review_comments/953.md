**Blocking: nested folders are not created, but success is reported.** `CreateAttributeFolders` with `["ZZT", "A", "B"]` returns `success`. Afterwards only `ZZT` exists, and `MoveAttributesAndFolders` into `ZZT/A` or `ZZT/A/B` answers "not found".

The cause: `ACAPI_Attribute_CreateFolder` takes an **in/out** folder and rewrites its `path`/`guid`. The level-by-level loop keeps pushing names onto that same `current`, so every level after the first is built on the rewritten path. The DevKit says the function "will create all folders along the path, if they do not exist" and returns `NoError` when the whole path already exists.
